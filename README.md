# jv-legal

Public hosting for the privacy policy and terms of the **JV Tracker** publishing
tool, because TikTok's Content Posting API review requires both at a real,
reachable URL — a placeholder is one of the two most common rejection reasons.

**This repo is public ON PURPOSE and contains no code and no credentials.**
The application itself lives in a private repository. Nothing here should ever
gain a source file.

Served by GitHub Pages from `main` / root:
- https://itsjoeyviola.github.io/jv-legal/
- https://itsjoeyviola.github.io/jv-legal/privacy.html
- https://itsjoeyviola.github.io/jv-legal/terms.html

Source of truth for both documents is `docs/` in the private app repo; this is a
published copy. Edit there, copy here.
